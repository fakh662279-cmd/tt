# TT Teacher Management System

## Documentation

### Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/fakh662279-cmd/tt.git
   ```
2. Navigate to the project directory:
   ```bash
   cd tt
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Features
- **User Authentication:** Secure login for teachers.
- **Course Management:** Add, edit, and delete courses.
- **Student Management:** Track student attendance and grades.
- **Reporting:** Generate performance reports for teachers and students.

### Usage Guide
1. After setting up the system, run the application:
   ```bash
   npm start
   ```
2. Open your browser and go to `http://localhost:3000`.
3. Use the provided login credentials to log in and access the features.
